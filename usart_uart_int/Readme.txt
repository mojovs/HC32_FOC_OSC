平台说明
================================================================================
本工程由 XHSC 官方 usart_uart_int 样例移植到 SMotorDrive 板
（HC32F460KETA + DRV8301），只保留 MDK 工程。

工程位置：
    code\example\usart_uart_int\MDK\usart_uart_int.uvprojx

驱动库位置：
    code\HC32F460_DDL_Rev3.3.0\drivers

================================================================================
硬件连接（SMotorDrive）
================================================================================
调试串口：USART3
    MCU PB6  -> USART3_TX (GPIO_FUNC_32) -> 座 CN1-3 (UART_TX)
    MCU PB7  -> USART3_RX (GPIO_FUNC_33) -> 座 CN1-2 (UART_RX)
    座 CN1：1=GND, 2=UART_RX, 3=UART_TX, 4=3.3V（以当前网表为准）
    参数：115200-8-N-1

时钟：
    外部晶振 16MHz -> MPLL 200MHz
    HCLK 200MHz / PCLK1 100MHz
    USART 时钟 = PCLK1 / 64 = 1.5625MHz

    说明：板上 X3 已确认为 16MHz。若以后更换晶振，必须同步修改
    XTAL_VALUE、PLLM/PLLN 和 CLK_XTAL_DRV_xxx。

================================================================================
功能描述
================================================================================
USART3 配置为 UART 模式，支持双向通信：
    - RX：中断方式，收到的字节写入环形缓冲区；
    - 主循环调用 UART_ReadByte() 取出字节：
          普通字符原样回显；
          '?'  打印帮助（演示 MCU printf -> 上位机）；
          '1'  打印状态。
    - printf 已重定向到 USART3（阻塞发送），可以直接使用：
          printf("count=%lu\r\n", (unsigned long)count);

对外接口：
    UART_Init()      初始化引脚、外设时钟、波特率和 RX 中断
    UART_SendByte()  阻塞发送 1 字节
    UART_ReadByte()  从 RX 环形缓冲区取 1 字节（非阻塞）
    fputc()          printf 重定向

printf 使用说明：
    - fputc() 已重定向到 USART3，Keil MDK MicroLIB 下可直接使用 printf；
    - 阻塞发送：115200 下 1 个字符约 87us，10 个字符约 0.87ms；
    - 不要在中断服务函数里调用 printf；
    - 字符串结尾建议用 \r\n，否则部分串口助手不会换行；
    - 如果 printf 影响电机控制时序，可改为“环形缓冲区 + TX 中断”方式。

说明：
    - 已移除之前用于判断 UART 是否正常的 LED 闪烁、心跳打印等辅助测试代码；
    - 上电后串口不会主动输出，发送 '?' 或 '1' 即可看到 MCU 的 printf 回复。

================================================================================
使用步骤
================================================================================
1）用 USB-UART 适配器连接 PC 和板上调试口（TX/RX 交叉，共地）。
2）打开串口助手，配置：
      波特率：115200
      数据位：8
      校验位：None
      停止位：1
3）打开 MDK 工程并重新编译。
4）下载代码到板子并全速运行。
5）在串口助手输入普通字符，窗口会原样回显。
6）输入 '?' 查看命令帮助，输入 '1' 打印状态（演示 MCU printf 回复）。

================================================================================
无反应时的排查顺序
================================================================================
1）发送 '1' 或 '?'，看是否收到 MCU 回复：
   - 收到回复：RX 和 TX 都正常；
   - 完全没回复：先查接线（适配器 TX -> CN1-2，RX -> CN1-3，GND -> CN1-1）；
     再尝试把适配器的 TX/RX 对调。注意 CN1-4 是 3.3V，不能接 GND。
2）适配器自测：拔掉板上接线，短接适配器自己的 TX/RX，
   串口助手发字符应回显；不回显就是适配器 RX/驱动/COM 口问题。
3）确认共地：适配器 GND 必须接 CN1-1，只接 TX/RX 不接地会收不到数据。
   CN1-4 是 3.3V 输出，接错会短路，务必不要接到 GND。
4）确认适配器电平为 3.3V TTL（不要用 RS-232 电平）。
5）确认串口助手设置为 115200-8-N-1，且没有开启流控。
6）确认程序确实运行：可用调试器看是否停在 SystemClockInit() 或
   DDL_AssertHandler()；本工程已移除 LED 启动指示，不再通过 LED 判断。

================================================================================
移植到其他项目
================================================================================
需要复制的 UART 相关代码：
    - main.c 中的 UART_Init()
    - UART_SendByte() / UART_ReadByte()
    - fputc()（printf 重定向）
    - USART_RxFull_IrqCallback() / USART_RxError_IrqCallback()
    - INTC_IrqInstalHandler()
    - m_au8DataBuf[] / m_stcRingBuf（RX 环形缓冲区）
    - ring_buf.c / ring_buf.h

需要按目标工程修改的宏：
    - USART_RX_PORT / USART_RX_PIN / USART_RX_GPIO_FUNC
    - USART_TX_PORT / USART_TX_PIN / USART_TX_GPIO_FUNC
    - USART_UNIT / USART_FCG_ENABLE()
    - USART_RX_ERR_IRQn / USART_RX_ERR_INT_SRC
    - USART_RX_FULL_IRQn / USART_RX_FULL_INT_SRC
    - RING_BUF_SIZE

注意：
    1. 波特率依赖 PCLK1 和 USART_CLK_DIV64。换工程后若 PCLK1 不是
       100MHz，需要重新选择 u32ClockDiv，或让 DDL 重新计算 BRR。
    2. 中断源编号必须与目标 USART 单元一致（本工程为 USART3）。
    3. UART_Init() 调用前需要先解除 GPIO/FCG 等外设写保护：
           LL_PERIPH_WE(LL_PERIPH_GPIO | LL_PERIPH_FCG | ...);
    4. Keil MDK 需要勾选 Use MicroLIB，printf 才会走 fputc()。

================================================================================
注意
================================================================================
1）PB6/PB7 属于 Func_Grp2，必须使用 GPIO_FUNC_32/33，不能按 Func0~15 配置。
2）工程相对路径已改为指向 code\HC32F460_DDL_Rev3.3.0\drivers。
3）本工程使用外部 16MHz 晶振（PH0/PH1）作为 MPLL 源。
   板上 X3 已确认为 16MHz；若更换晶振，必须同步修改 XTAL_VALUE、
   PLLM/PLLN 和 CLK_XTAL_DRV_xxx。
4）FCG0 在复位后是写保护的；CLK_SetSysClockSrc(PLL) 会断言 PRT0 == 1，
   因此 LL_PERIPH_WE 必须包含 LL_PERIPH_FCG，且 LL_PERIPH_WP 不要再锁 FCG。
5）Debug 构建定义了 __DEBUG，DDL_ASSERT 生效；若时钟配置异常，程序会停在
   DDL_AssertHandler() 的死循环里。
